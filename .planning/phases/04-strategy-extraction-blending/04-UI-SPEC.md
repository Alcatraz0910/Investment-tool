# Phase 4 — UI Design Contract

> Visual and interaction contract for Phase 4: Strategy Extraction & Blending.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

Phase 4 adds NO new pages or routes. All UI extends the existing `/dashboard?tab=creators` view.
Four additions are made to the existing layout:

1. **Strategy card section** — appended below the transcript list on each tracked creator card.
   Contains: allocation rows, confidence badge, "last extracted" timestamp, optional contradiction
   diff panel.
2. **Trust weight controls** — appended below the strategy card on each tracked creator card.
   Contains: global slider + "Customize per category" toggle + 8 per-category sliders.
3. **Step-status extension** — "Extracting strategy..." appended as Step 6 to the existing Phase 3
   step-status line below the Refresh button.
4. **Blend Summary card** — a new standalone card appended at the bottom of the Creators tab,
   below the creator list.

## Color

Inherited unchanged from Phase 3. Phase 4 adds amber (warning) as a new semantic color for
contradiction detection. Amber is used exclusively for contradiction states — not for any other
element.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#18181B` (zinc-900) | Page background |
| Secondary (30%) | `#27272A` (zinc-800) + `#3F3F46` (zinc-700) border | Cards, strategy card, trust weight section |
| Accent (10%) | `#6366F1` (indigo-500) | Interactive elements — explicit list below |
| Accent hover | `#818CF8` (indigo-400) | Hover state for accent elements |
| Warning | `#F59E0B` (amber-500) / `amber-400` text | Contradiction badge and diff rows ONLY |
| Destructive | `#F87171` (red-400) text | Extraction failure warning text ONLY |
| Success confirm | `#34D399` (emerald-400) text | Auto-save green tick ONLY |

Accent (`#6366F1` / `#818CF8`) reserved for:
- [Refresh] button (inherited from Phase 3)
- Focus ring on all interactive elements (`focus:ring-2 focus:ring-indigo-500`)
- Active tab underline (inherited from Phase 2)
- "Tracking" button border/text (inherited from Phase 2)
- "Customize per category" toggle text (`text-indigo-400`)
- Slider thumb accent (`accent-indigo-500` on `<input type="range">`)

Accent NOT used for:
- Confidence badge (uses green/amber/red semantic scale — see Component Specs)
- Allocation progress bars (use `bg-indigo-500/40` fill — muted, not full accent)
- Contradiction badge (uses amber, not indigo)
- Auto-save tick (uses emerald-400, not indigo)

Confidence badge color scale (three tiers):
- High (≥70%): `bg-emerald-500/10 text-emerald-400 border border-emerald-500/20`
- Medium (40–69%): `bg-amber-500/10 text-amber-400 border border-amber-500/20`
- Low (<40%): `bg-red-500/10 text-red-400 border border-red-500/20`

Rationale: The three-tier scale maps semantic confidence to color meaning — green = reliable,
amber = uncertain, red = unreliable. Matches STRAT-03 requirement for confidence score display.
Reuses the established chip pattern from Phase 3 status chips.

Source: `03-UI-SPEC.md` Color section; `creators-tab.tsx` line 95.

## Component Specs

### 1. Strategy Card Section (per tracked creator)

Appended directly below the transcript list expand/collapse area. Visible on all tracked creators
that have been refreshed at least once. Hidden if creator has never been refreshed.

**Container:**
```
bg-zinc-800/50 border border-zinc-700/50 rounded-lg mt-2 p-4
```

**Section heading row:**
```
flex items-center justify-between mb-3
```
- Left: `text-sm font-semibold text-zinc-400 uppercase tracking-wide` → "STRATEGY"
- Right: confidence badge (see below) + "Last extracted: {D MMM YYYY}" in `text-sm text-zinc-500`

**Confidence badge:**
```
inline-flex items-center px-2 py-1 rounded text-sm font-semibold
```
Color class determined by tier (see Color section). Badge text: `"{n}% confidence"`.

**Allocation rows:**
One row per category present in `allocation JSONB`. Categories omitted by Claude are NOT shown
(consistent with CONTEXT.md D-discretion: no zero-fill).

Row layout:
```
flex items-center gap-3 py-2 border-b border-zinc-700/30 last:border-0
```
- Category name: `text-sm text-zinc-300 w-32 shrink-0`
- Progress bar container: `flex-1 bg-zinc-700/50 rounded-full h-1.5`
- Progress bar fill: `bg-indigo-500/40 rounded-full h-1.5` — width = `{allocation_pct}%`
- Percentage value: `text-sm font-semibold text-zinc-100 w-10 text-right`

Row order: descending by allocation percentage (highest first).

**Empty state (no strategy extracted yet):**
Container with inner text: `text-sm text-zinc-500 italic py-2`
Copy: "No strategy extracted yet. Run Refresh to extract this creator's allocation."

**Extraction failure warning (D-02 non-blocking error):**
Shown below the strategy container when `extractionWarning` is present in the refresh response.
```
text-sm text-red-400 mt-1
```
Copy: "Transcripts refreshed. Strategy extraction failed — try again later."
This is a plain text line (no background, no border) — same pattern as Phase 3 error state.

### 2. Contradiction Diff Panel (D-11)

Shown inside the strategy card section when `has_contradiction = true` on the latest strategy row.
Positioned directly below the allocation rows and above the trust weight controls.

**Badge (always visible when contradiction active):**
```
inline-flex items-center gap-1.5 px-2 py-1 rounded
bg-amber-500/10 border border-amber-500/20 text-amber-400 text-sm font-semibold
```
Left of badge: amber warning icon — inline SVG triangle with exclamation (12px).
Badge text: "Strategy shift detected"

**Expand/collapse toggle for diff table:**
Chevron icon (same inline SVG pattern as Phase 3 transcript list toggle). Appended to the right
of the badge in a `flex items-center gap-2` row. The entire row is clickable.
- Collapsed by default
- Chevron rotates 180deg on expand: `transition-transform duration-200`
- `aria-expanded`, `aria-controls` pointing to diff table container ID

**Diff table container:**
```
bg-amber-500/5 border border-amber-500/15 rounded-lg mt-2 overflow-hidden
```

**Diff table header row:**
```
grid grid-cols-[1fr_auto_auto_auto] gap-4 px-4 py-2 border-b border-amber-500/15
text-sm font-semibold text-zinc-400 uppercase tracking-wide
```
Columns: Category | Was | Now | Change

**Diff table data rows:**
```
grid grid-cols-[1fr_auto_auto_auto] gap-4 px-4 py-2 border-b border-amber-500/10 last:border-0
```
- Category name + optional ⚠ flag icon (12px, amber-400) — shown only when `|delta| > 15`
- Was value: `text-sm text-zinc-400` → `"{old}%"`
- Now value: `text-sm text-zinc-300` → `"{new}%"`
- Change: `text-sm font-semibold` — positive delta: `text-emerald-400` "+" prefix; negative delta: `text-red-400`

Rows for ALL categories in either old or new allocation are shown. Only rows with `|delta| > 15`
display the ⚠ icon — others show no icon (context rows).

Auto-clear behaviour (D-12): When the latest `creator_strategies` row has `has_contradiction = false`,
the badge and diff table are NOT rendered. No user action required.

### 3. Trust Weight Controls (D-08 / D-09)

Appended below the strategy card section within the same creator card. Inline — no separate card.

**Section heading:**
```
text-sm font-semibold text-zinc-400 uppercase tracking-wide mt-4 mb-2
```
Text: "TRUST WEIGHT"

**Global slider row:**
```
flex items-center gap-3
```
- Label: `text-sm text-zinc-300 w-32 shrink-0` → "Global"
- Slider: `flex-1 accent-indigo-500 min-h-[44px]` — `type="range"` min=0 max=100 step=1
- Value display: `text-sm font-semibold text-zinc-100 w-10 text-right` → `"{value}%"`
- Save confirm tick: `text-emerald-400 text-sm` → "✓" — shown for 1500ms after `onMouseUp`/`onTouchEnd` save, then hidden

**"Customize per category" toggle:**
```
flex items-center gap-1.5 mt-3 cursor-pointer
```
- Chevron icon (12px inline SVG): `text-zinc-500` rotates from right→down on expand
- Label: `text-sm text-indigo-400 hover:text-indigo-300`
- Text: "Customize per category" (collapsed) / "Customize per category" (expanded — text unchanged, only chevron rotates)
- `aria-expanded`, `aria-controls` pointing to per-category sliders container ID

**Per-category sliders container:**
Collapsed by default. Revealed via Framer Motion `AnimatePresence` + `motion.div` with
`initial={{ height: 0, opacity: 0 }}` → `animate={{ height: 'auto', opacity: 1 }}` →
`exit={{ height: 0, opacity: 0 }}`. Duration: 200ms ease-out.

Container class (inner): `mt-2 space-y-1`

Each of the 8 per-category slider rows:
```
flex items-center gap-3 py-2
```
- Category label: `text-sm text-zinc-300 w-32 shrink-0` → e.g. "Tech", "Dividends", "Bonds", etc.
- Slider: `flex-1 accent-indigo-500` — same range input spec as global slider
- Value display: `text-sm font-semibold text-zinc-100 w-10 text-right` → `"{value}%"`
- Save confirm tick: same emerald-400 "✓" pattern as global slider

Category order (fixed, matches `AssetCategory` enum order):
Tech → Dividends → Bonds → Commodities → Cash → Emerging Markets → Small Cap → REITs

Initial value for each per-category slider: if a `user_creator_category_weights` row exists for
this creator + category, use that value. Otherwise, inherit the global `trust_weight` value as
the displayed default (no override stored until the user moves the slider).

**Auto-save behaviour (D-10):**
- Save fires on `onMouseUp` + `onTouchEnd` only — NOT on `onChange`
- Calls server action `saveCreatorWeight({ userCreatorId, category, weight })`
- `category = null` for global slider; `category = "Tech"` etc. for per-category sliders
- Green tick displayed inline next to the saved slider for 1500ms
- No toast library, no Save button, no loading spinner during save

### 4. Step-Status Extension (D-03)

Extends the existing Phase 3 step-status line. No visual changes to the existing 5 steps.

New step appended as Step 6:

| State | Copy |
|-------|------|
| Running | "Extracting strategy..." |
| Done (success) | included in completion summary (no separate "extraction done" line) |
| Done (warning — D-02) | "Transcripts refreshed. Strategy extraction failed — try again later." |

The extraction failure warning uses `text-sm text-red-400` — same as Phase 3 error state.
The completion summary (all steps including extraction succeeded) shows the existing Phase 3
summary copy unchanged — extraction success is silent (no extra line added to status).

Full step sequence (Phase 3 + Phase 4):
1. "Resolving channel..."
2. "Fetching videos... {n}/{total}"
3. "Fetching transcripts... {n}/{total}"
4. "Embedding chunks... {n}/{total} videos"
5. "Extracting strategy..." ← Phase 4 new step
6. On complete: "{fetched}/{total} transcripts fetched{, N pending retry}"
7. On extraction failure (non-blocking): "Transcripts refreshed. Strategy extraction failed — try again later."
8. On pipeline error: "YouTube API error — partial progress saved" (unchanged from Phase 3)

**Container:**

**Heading:**
```
text-lg font-semibold text-white mb-1

Text: "Blend Summary"

**Subheading / description:**
```
text-sm text-zinc-500 mb-4
```
Text: "How much each creator shapes this month's unified allocation."

**Influence rows (one per tracked creator with a strategy):**
```
flex items-center gap-3 py-2 border-b border-zinc-700/30 last:border-0

- Influence bar container: `w-32 bg-zinc-700/50 rounded-full h-1.5`

**Empty state (no tracked creators have a strategy yet):**
Single line inside the card: `text-sm text-zinc-500 italic`
Copy: "No strategy data yet. Refresh a creator to begin blending."

**Framing note (PLAN-04 / CLAUDE.md):**

## Interaction States

### Trust Weight Slider State

```
idle → [user drags slider] → dragging (local value update, no save)
dragging → [mouseup / touchend] → saving (server action call, tick hidden)
saving → [server action resolves] → saved (tick visible for 1500ms)
saved → [1500ms elapsed] → idle (tick hidden)
saving → [server action rejects] → error (red-400 "!" for 1500ms, then idle)
```

State is scoped per slider. Other sliders are unaffected.

### Customize Per Category Expand/Collapse

```
collapsed (default) → [toggle click] → expanded
expanded → [toggle click] → collapsed
```

Framer Motion `AnimatePresence` handles height animation (200ms ease-out).
State is local — not persisted. Re-collapses on page reload.

### Contradiction Diff Expand/Collapse

```
collapsed (default) → [badge row click] → expanded
expanded → [badge row click] → collapsed
```

State is local. Chevron rotates 180deg (`transition-transform duration-200`).

### Strategy Card Visibility

- Creator never refreshed: strategy card section NOT rendered
- Creator refreshed, no strategy extracted yet (extraction failed or first-time): empty state shown
- Creator refreshed, strategy exists: allocation rows shown
- `has_contradiction = true` on latest row: contradiction badge + diff panel shown
- `has_contradiction = false` on latest row: no badge, no diff panel

## Animation Contract

Framer Motion is already installed (Phase 3). Phase 4 uses it for one pattern only.

| Element | Animation | Spec |
|---------|-----------|------|
| Per-category sliders container | Height expand/collapse | `initial={{ height: 0, opacity: 0 }}` → `animate={{ height: 'auto', opacity: 1 }}` → `exit={{ height: 0, opacity: 0 }}` — `transition={{ duration: 0.2, ease: 'easeOut' }}` |
| Contradiction diff table | Height expand/collapse | Same spec as per-category sliders |
| Auto-save tick | Fade in/out | `initial={{ opacity: 0 }}` → `animate={{ opacity: 1 }}` — CSS `setTimeout` hide after 1500ms (no Framer needed — simple React state) |
| Allocation progress bars | No animation | Static width — no mount animation (Phase 6 glassmorphism phase adds layout animations) |
| Slider thumb | Browser default | No custom animation |

Chevron rotation (both toggles): Tailwind `transition-transform duration-200` class toggled by `rotate-180` — no Framer Motion needed for the icon itself.
