## Objective

Install dependencies, configure the test framework, create the Anthropic singleton client, fix the Pinecone chunk-text metadata gap (Pitfall 1 from RESEARCH.md), and create test stub files for all Phase 4 requirements.

This wave is a prerequisite for all Wave 1 work. Nothing in Wave 1 can proceed without the Anthropic SDK installed, the singleton client available, and the test stub files in place.

## Context

- **D-07:** `@anthropic-ai/sdk` is not installed. Must be installed before any extractor code can be written.

- **VALIDATION.md Wave 0:** All 4 test stub files must be created so Wave 1 executors can write tests against the stubs.
- **vitest:** No test framework exists in the project. Install vitest and create config.

  <title>Create lib/anthropic/client.ts Anthropic singleton</title>
  <read_first>

  </read_first>
  <action>
    Create the directory `pulse/src/lib/anthropic/` and the file `pulse/src/lib/anthropic/client.ts` with this exact content:

    ```typescript
    import 'server-only'
    import Anthropic from '@anthropic-ai/sdk'

    let cached: Anthropic | null = null

    /**
     * Anthropic singleton. Used for strategy extraction via tool_use.
     * Follows the singleton pattern of lib/openai/client.ts and lib/pinecone/client.ts.
     * RESEARCH Pattern 1. Model: claude-sonnet-4-6 (D-04).
     */
    export function getAnthropic(): Anthropic {
      if (cached) return cached
      const key = process.env.ANTHROPIC_API_KEY
      if (!key) {
        throw new Error(
          'ANTHROPIC_API_KEY is not set. ' +
          'Add it to .env.local. ' +
          'Get one from https://console.anthropic.com/settings/keys'
        )
      }
      cached = new Anthropic({ apiKey: key })
      return cached
    }
    ```

    The `import 'server-only'` at the top causes a build-time error if this module is ever imported from a client component — this ensures ANTHROPIC_API_KEY never reaches the browser bundle (RESEARCH Security Pattern).
