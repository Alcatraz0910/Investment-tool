## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding |
| sm | 8px | Inline element spacing, chip padding |
| md | 16px | Default element spacing, card inner padding |
| lg | 24px | Card padding (glassmorphism cards use `p-6` = 24px) |
| xl | 32px | Section gaps within a tab panel |
| 2xl | 48px | Major section breaks between tab sections |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions:
- Touch targets on accordion toggle rows: minimum 44px height (WCAG 2.5.5 AA).
- `max-w-4xl` page container (~896px) — set in `page.tsx` per D-04, no spacing token needed.

Source: 8-point scale standard; D-04 for max-width; WCAG for touch targets.

**Accent reserved for:**

**Accent NOT used for:**
- Passive text
- Table row hover states (use `hover:bg-white/5` instead)
- Borders on glassmorphism cards (use `border-white/10`)

Source: `06-CONTEXT.md` D-01 + RESEARCH.md `<specifics>` block + Recharts color assignments.

## Glassmorphism Rules

Glassmorphism only works when the page background is the solid `#1C1C1E` base. Rule: **never nest a `bg-white/5` card inside another `bg-white/5` card** without a solid surface between them.

Hierarchy:
1. `<body>` / `<main>` — solid `bg-base` (`#1C1C1E`)
2. Glassmorphism cards — `backdrop-blur-xl bg-white/5 border border-white/10 rounded-xl`
3. Solid surface elements within cards — `bg-surface border border-border`

Source: RESEARCH.md Pitfall 6.

## Animation Contract

### Tab Content Fade (D-11.2)

Component: `AnimatedTabPanel.tsx` (new client wrapper)

```
initial: { opacity: 0, y: 8 }
animate: { opacity: 1, y: 0 }
exit:    { opacity: 0, y: -8 }
transition: { duration: 0.2, ease: 'easeOut' }
mode: 'wait'
key: activeTab
```

### Card Mount Stagger (D-11.1)

Applied to: StrategyCard list (creators-tab), BuyList rows (BuyListTable), BlendSummary.

Parent variants:
```
hidden:  { opacity: 0 }
visible: { opacity: 1, transition: { staggerChildren: 0.05 } }
```

Child variants:
```
hidden:  { opacity: 0, y: 8 }
visible: { opacity: 1, y: 0, transition: { duration: 0.25, ease: 'easeOut' } }
```

### Ticker Rationale Accordion (D-09/D-13)

```
initial: { height: 0, opacity: 0 }
animate: { height: 'auto', opacity: 1 }
exit:    { height: 0, opacity: 0 }
transition: { duration: 0.2, ease: 'easeOut' }
overflow: hidden
```

All animations: import from `'framer-motion'` (matches `package.json` dependency name — not `'motion/react'`).

Duration range enforced: 150ms – 400ms. No animation exceeds 400ms.

Source: `06-CONTEXT.md` D-11/D-12/D-13; RESEARCH.md Pattern 2, 3, 4.

## BuyListTable Structure Change

Current: `<table>` with `<tr>` rows.
Phase 6: Convert to `<div>` flex list. Each buy item = glassmorphism row card. Rationale: `AnimatePresence` height animation on `<tr>` is awkward. Div list matches glassmorphism aesthetic (D-02).

Each row card displays: ticker | category | £ amount | allocation gap bar.
Expanded rationale shows: category, current allocation %, target allocation %, gap %, "closes X% of gap."

Source: RESEARCH.md Pattern 4 + Open Question 4 recommendation.
