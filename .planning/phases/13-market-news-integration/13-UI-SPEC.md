- News badges (informational signal, not conviction — use zinc)
- Macro theme pills
- Staleness indicator text

- `text-amber-400` — news staleness indicator when `fetched_at` > 24h ago (matches existing price stale pattern)
- `text-green-400` — positive macro theme sentiment
- `text-zinc-400` — neutral macro theme sentiment
- `text-red-400` — negative macro theme sentiment + error messages
- `text-zinc-500` — news badge when count = 0; placeholder/empty text

Primary visual anchor: the "This Month's Context" panel — positioned between the heading row and the creator sections. It is the only element on the tab that synthesises all data sources (creator signals + macro news) into a single paragraph, making it the highest-information element above the fold.

Within each creator section, the existing focal point (creator name + budget) is unchanged.

## New Component Specifications

### 1. "This Month's Context" Panel (NEWS-06)

**Position:** Between the heading row and the price error banner / creator sections. Rendered regardless of whether prices have been refreshed.

**Container:**
```
backdrop-blur-xl bg-white/5 border border-white/10 rounded-xl p-4 space-y-2
```
Matches existing creator section card style exactly.

**Panel header row** (`flex items-center justify-between gap-3`):
- Left group (`flex items-center gap-2`):
  - Heading: `text-base font-semibold text-white` — "This Month's Context"
  - Staleness indicator: `text-xs` — see Staleness Indicator spec below
- Right group (`flex items-center gap-2`):
  - "Refresh News" button (see Refresh News Button spec below)
  - Collapse chevron: inline SVG `w-4 h-4 text-zinc-400`, rotates 180deg when expanded

**Panel body** (collapsible, default expanded):
- Default state: expanded (`max-h` transition, `overflow-hidden`)
- Context summary: `text-sm text-zinc-300 leading-relaxed` — the 3-4 sentence AI paragraph
- Disclaimer: `text-xs text-zinc-500 mt-2` — fixed disclaimer string (see Copywriting Contract)
- Empty state (no cache yet): `text-sm text-zinc-500 italic` — "No news summary yet. Click Refresh News to generate this month's context."

**Props required on WatchListTab:**
```typescript
contextSummary: string | null        // from news_cache.context.context_summary
newsLastFetchedAt: Date | null       // from news_cache.fetched_at
tickerCounts: Record<string, number> // from news_cache.context.ticker_counts
macroThemes: Array<{ sector: string; theme: string; sentiment: 'positive' | 'neutral' | 'negative' }>
                                     // from news_cache.context.macro_themes
```

### 2. Staleness Indicator

**Position:** Inline in the "This Month's Context" panel header, after the heading text.

**Logic:**
- If `newsLastFetchedAt` is null: render nothing (no last-updated text)
- If `newsLastFetchedAt` is >24h ago: `text-xs text-amber-400` — "Last updated: {relative time} — stale"
- If `newsLastFetchedAt` is ≤24h ago: `text-xs text-zinc-500` — "Last updated: {relative time}"

**Relative time format** (no library — hand-rolled):
- < 1 hour: "X minutes ago"
- 1–23 hours: "X hours ago"
- ≥ 24 hours: "X days ago"

**Tailwind:**
```
// Fresh (≤24h)
text-xs text-zinc-500

// Stale (>24h)
text-xs text-amber-400
```

### 3. Refresh News Button

**Position:** Right side of "This Month's Context" panel header row.

**Style:** Ghost/secondary (NOT accent primary — news refresh is a secondary action relative to the primary content).
```
text-sm font-semibold text-zinc-400 hover:text-white border border-zinc-700 rounded-md px-3 min-h-[44px] disabled:opacity-60 focus:outline-none focus:ring-2 focus:ring-indigo-500 flex items-center gap-2
```

**States:**
- Idle: text `"Refresh News"`, no icon
- Loading: `<SpinnerSVG />` (reuse existing component) + `disabled={true}`
- On success: panel body re-renders with new context summary
- On error: error banner appears below panel (see Error States)

**Important:** "Refresh News" and "Refresh Prices" are independent actions. They cannot be triggered simultaneously — disable both buttons while either is loading.

### 4. News Badge (per ticker row, NEWS-04)

**Position:** New column "News" in each ticker table — inserted after the "Signal" column and before "Price".

**Badge style (count > 0):**
```
text-xs font-semibold text-zinc-400 bg-zinc-700/50 border border-zinc-600/30 rounded px-1.5 py-0.5
```
Content: `"{N} news"` (e.g. `"3 news"`, `"1 news"`)

**Badge style (count = 0 or ticker not in tickerCounts):**
```
text-xs text-zinc-600
```
Content: `"—"` (em dash, aria-label="No relevant news")

**Why zinc, not indigo:** News count is informational context, not a conviction signal. Using indigo would imply an actionable quality it does not have.

**Column spec (added to existing ticker table):**

| Col | Header | Alignment | Width |
|-----|--------|-----------|-------|
| (existing) Holding | `Holding` | left | auto (flex-1) |
| (existing) Conviction | `Conviction` | left | fixed 80px |
| (existing) Signal | `Signal` | left | fixed 88px |
| **(new)** News | `News` | left | fixed 72px |
| (existing) Price | `Price` | right | fixed 72px |
| (existing) Qty | `Qty` | right | fixed 48px |
| (existing) Spend | `Spend` | right | fixed 64px |

Table header for new column: `text-xs font-semibold text-zinc-500 uppercase tracking-wide py-2`

**Same column added to "All Picks" merged table**, replacing the existing "Creators" column position (append after "Creators").

### 5. Macro Themes Strip (per creator, NEWS-05)

**Position:** Inside the creator section card, below the creator header row and above the ticker table. Only rendered when `macroThemes.length > 0` for themes relevant to that creator's sectors.

**Layout:** Horizontal flex wrap (`flex flex-wrap gap-2 py-1`).

**Pill per theme:**
```
flex items-center gap-1.5 text-xs rounded-full px-2.5 py-1 bg-zinc-800/60 border border-white/10
```

**Sentiment dot** (left of text):
```
// positive
w-1.5 h-1.5 rounded-full bg-green-400 flex-shrink-0

// neutral
w-1.5 h-1.5 rounded-full bg-zinc-400 flex-shrink-0

// negative
w-1.5 h-1.5 rounded-full bg-red-400 flex-shrink-0
```

**Pill text:** `text-xs text-zinc-300` — `"{sector}: {theme}"` (e.g. "Technology: AI chip demand rising")

**Empty state:** If no macro themes for this creator's sectors, render nothing (no empty message — absence is silent).

**Maximum pills shown:** 3 per creator card (truncate beyond 3 silently — avoids card bloat). If more than 3 themes exist, show first 3 from the `macroThemes` array.

## Interaction Contracts

### Refresh News Flow (NEWS-06, NEWS-07)

1. User clicks "Refresh News" button in the context panel header.
2. "Refresh News" button shows `<SpinnerSVG />` and is disabled. "Refresh Prices" button also disabled.
3. Server action `refreshNewsAndSummary()` runs: Finnhub fetch → RSS fetch → Claude generate_news_context → Supabase UPSERT.
4. On success:
   - Context panel body updates with new summary text.
   - Staleness indicator resets to "just now" / fresh color.
   - News badges on all ticker rows update with new counts.
   - Macro theme pills per creator section update.
   - Both buttons re-enabled.
5. On partial error (e.g. RSS feed timeout but Finnhub succeeded):
   - Context panel still updates with partial data.
   - Error banner below context panel: `text-sm text-red-400 role="alert" aria-live="assertive"` — "News refresh partially failed. Some feeds were unavailable. Summary generated from available data."
6. On full error:
   - Context panel body unchanged (keeps previous cached data if any).
   - Error banner: "News refresh failed. Check your connection and try again."
   - Both buttons re-enabled.

**No auto-trigger:** `refreshNewsAndSummary` is never called on tab mount, tab switch, or page load. Manual button only (v1 manual-first constraint from CLAUDE.md).

### Collapse/Expand Context Panel

1. "This Month's Context" panel is expanded by default on first render.
2. User clicks the chevron (or anywhere in the panel header row) to collapse.
3. Body collapses with CSS transition: `max-h` from `max-h-96` to `max-h-0`, `overflow-hidden`, `transition-all duration-200 ease-out`.
4. Chevron rotates 180deg (CSS `rotate-180`) when expanded. Returns to 0deg when collapsed.
5. State is local React state (`useState(true)` for `isExpanded`) — not persisted.

### News Badge Interaction

Badges are display-only — no click action, no tooltip, no expand. Informational only.

### Staleness Check on Tab Render

On tab render, `newsLastFetchedAt` is read from the `newsLastFetchedAt` prop (passed from RSC page.tsx). No client-side fetch on mount. Staleness is computed purely from the prop timestamp vs `Date.now()`.

## Accessibility Baseline

Inheriting Phase 12 baseline. Phase 13 additions:

- "Refresh News" button: `focus:outline-none focus:ring-2 focus:ring-indigo-500`, `min-h-[44px]`
- Chevron toggle: `aria-expanded={isExpanded}` on the button element; `aria-controls="news-context-body"`; panel body has `id="news-context-body"`
- Context panel body: `role="region"` with `aria-label="This month's market context summary"`
- News refresh error banner: `role="alert" aria-live="assertive"`
- News badge `—` (zero news): `aria-label="No relevant news"` on the span
- News badge with count: no additional aria needed; visible text is sufficient
- Macro theme pills: decorative; visible text is sufficient; no additional aria
- Staleness "stale" indicator: `aria-label="News data is more than 24 hours old"` on the amber span
- Collapse/expand: entire panel header row is not a button — only the chevron icon is the button target (avoid making the heading text a click target to prevent accidental collapses)
