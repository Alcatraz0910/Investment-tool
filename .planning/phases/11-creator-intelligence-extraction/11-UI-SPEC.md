# Phase 11 — UI Design Contract

> Visual and interaction contract for the Creator Search feature in Phase 11.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> **Scope note:** Phase 11 UI change is narrow — one new section inside `creators-tab.tsx`.
> The search bar replaces the URL input as the primary creator-add flow. The URL input
> is preserved as a collapsed fallback. No new pages, routes, or modal layers.

## Component Inventory

### 1. Search Bar Section

Container: `bg-zinc-800/50 border border-zinc-700 rounded-lg p-4 mt-6`

Heading: `text-lg font-semibold text-white mb-3` — copy: "Find a Creator"

Search form layout: `flex gap-2` (input + button side-by-side on one row)

**Search input:**
- Classes: `flex-1 px-4 py-3 min-h-[44px] bg-zinc-900 border border-zinc-700 rounded-md text-base text-white placeholder:text-zinc-500 focus:outline-none focus:ring-2 focus:ring-indigo-500 focus:border-transparent`
- `name="channelQuery"`, `type="text"`, `autocomplete="off"`, `autocorrect="off"`, `spellcheck="false"`
- Fires ONLY on form submit (Enter key or button press). 500ms debounce on input event for visual feedback only — no API call on keypress.

**Search submit button:**
- Classes: `bg-indigo-500 hover:bg-indigo-400 disabled:opacity-60 disabled:cursor-not-allowed text-white text-sm font-semibold rounded-md px-4 min-h-[44px] focus:outline-none focus:ring-2 focus:ring-indigo-500`
- Copy: "Search" (idle), "Searching…" (pending)
- `type="submit"`, disabled when `searchPending === true`

### 2. Search Result List

Wrapper: `mt-3` — rendered only when `searchState.results` exists (including empty array)

Animation: Framer Motion `AnimatePresence` on the list container. List fades in with `initial={{ opacity: 0, y: 6 }}`, `animate={{ opacity: 1, y: 0 }}`, `exit={{ opacity: 0 }}`, `transition={{ duration: 0.2, ease: 'easeOut' }}`. Individual items stagger with `staggerChildren: 0.04`.

**Result card:**
- Layout: `flex items-center gap-3 py-2.5 border-b border-zinc-700/50 last:border-b-0`
- Thumbnail: `<img>` 40×40px, `rounded-full`, `object-cover`, `shrink-0`, `bg-zinc-700` as fallback background when `thumbnailUrl` is null
- Channel name: `text-base font-semibold text-white flex-1 min-w-0 truncate`
- Subscriber count: `text-sm text-zinc-400` — formatted as "1.2M subscribers", "500K subscribers", "12K subscribers"; hidden (empty string) when `subscriberCount` is null
- Track button: `text-sm font-semibold rounded-md px-3 min-h-[36px] focus:outline-none focus:ring-2 focus:ring-indigo-500`
  - Untracked state: `text-zinc-400 border border-zinc-700 hover:border-indigo-500 hover:text-indigo-400`
  - Tracked state: `text-indigo-400 border border-indigo-500/50 opacity-60 cursor-not-allowed` — copy: "Tracking ✓", `disabled`
  - Pending (track action firing): `disabled:opacity-60 disabled:cursor-not-allowed`

### 3. "Add by URL instead" Disclosure Toggle

Placement: below search results area (always visible, regardless of results state)

Toggle trigger: `<button type="button">` — `text-sm text-zinc-400 hover:text-zinc-300 underline underline-offset-2 mt-4 focus:outline-none focus:ring-2 focus:ring-indigo-500 rounded`

Copy: "Add by URL instead" (collapsed), "Hide URL form" (expanded)

Animation: Framer Motion `AnimatePresence` on the URL form wrapper. `initial={{ opacity: 0, height: 0 }}`, `animate={{ opacity: 1, height: 'auto' }}`, `exit={{ opacity: 0, height: 0 }}`, `transition={{ duration: 0.2, ease: 'easeOut' }}`. Add `overflow: hidden` to wrapper.

URL form content: identical to current "Add Custom Creator" form in `creators-tab.tsx` — no visual changes to the form itself. The outer container `bg-zinc-800/50 border border-zinc-700 rounded-lg p-4 mt-3` is preserved as-is.

### 4. Loading State

When `searchPending === true`: show a `<p className="text-sm text-zinc-400 mt-3">Searching YouTube…</p>` below the search form. Hide when pending resolves.

Alternatively, the submit button label change ("Searching…") alone is sufficient if the results appear quickly. Both cues together are preferred.

### 5. Empty Results State

When `searchState.results` exists AND `results.length === 0`:
- `<p className="text-sm text-zinc-400 mt-3 py-4 text-center">No channels found for "{query}". Try a different name or add by URL instead.</p>`

### 6. Error State

When `searchState.error` exists:
- `<p role="alert" aria-live="polite" className="text-sm text-red-400 mt-2">{error}</p>`
- Error copy: "Search failed. Check your connection and try again." (network/server error)
- Error copy: "Please enter a channel name to search." (empty query guard)

## Interaction Contract

| Interaction | Behaviour |
|-------------|-----------|
| Type in search input | Visual update only — no API call. 500ms debounce for potential future type-ahead (not used in Phase 11). |
| Press Enter / click Search | Fires `searchAction(formData)`. Disables button. Shows "Searching…" copy. |
| Search completes — results | `AnimatePresence` animates result list into view. Search input remains populated. |
| Search completes — no results | Empty state paragraph shown. No list rendered. |
| Search completes — error | Error paragraph shown. List cleared. |
| New search fires | Previous results cleared immediately (show loading state). |
| Click "Track" on result | Fires `trackSearchedCreator` action. Button switches to "Tracking ✓" (disabled) optimistically. |
| Click "Add by URL instead" | Toggles URL form visibility via Framer Motion height animation. Button label inverts. |
| URL form submit | Existing `customAction` behaviour unchanged — no changes to form UX. |
| Keyboard: Tab through results | Tab moves: search input → Search button → result Track buttons (in order) → "Add by URL instead" toggle |
| Keyboard: focus on Track button | Focus ring: `focus:ring-2 focus:ring-indigo-500` — matches existing button pattern |
| Screen reader: results appear | `aria-live="polite"` region wrapping result list announces count: "5 channels found." |

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Search input label | `<label htmlFor="channelQuery">Search YouTube channels</label>` — visually hidden with `sr-only` or shown as visible label above input |
| Result list ARIA | `role="list"` on `<ul>`, `role="listitem"` on each `<li>` |
| Live region for results | `aria-live="polite"` on a `<p>` that announces "N channels found" or "No channels found" after search completes |
| Track button ARIA | `aria-pressed` not applicable (stateful but not a toggle — use `aria-disabled` on tracked state, `aria-label="Track {channelTitle}"` to disambiguate multiple Track buttons) |
| Disclosure toggle ARIA | `aria-expanded={isUrlFormOpen}` on the toggle button; `aria-controls` pointing to URL form wrapper id |
| URL form | Existing `htmlFor` label associations unchanged |
| Thumbnail alt text | `alt="{channelTitle} channel thumbnail"` |
| Thumbnail missing | `alt=""` when `thumbnailUrl` is null and fallback background shown |

## Animation Contract

All animations use Framer Motion. No CSS transitions.

| Element | Pattern | Duration | Easing |
|---------|---------|----------|--------|
| Result list (enter) | `AnimatePresence` — `opacity: 0→1`, `y: 6→0` on list wrapper | 200ms | easeOut |
| Result items (stagger) | `staggerChildren: 0.04` — each item `opacity: 0→1`, `y: 4→0` | 180ms per item | easeOut |
| Result list (exit) | `opacity: 1→0` | 150ms | easeOut |
| URL form (open) | `height: 0→auto`, `opacity: 0→1` | 200ms | easeOut |
| URL form (close) | `height: auto→0`, `opacity: 1→0` | 150ms | easeOut |
| Existing creator list | Unchanged — `creatorListVariants` / `creatorItemVariants` stay as-is |

Framer Motion `AnimatePresence` is already imported in `creators-tab.tsx` (via the `motion` import from `framer-motion`). No new packages required.
