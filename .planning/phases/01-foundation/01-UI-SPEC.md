# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1 auth pages and dashboard placeholder.
> Generated by gsd-ui-researcher. Source: CONTEXT.md D-06, D-07; REQUIREMENTS.md AUTH-01, AUTH-02.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — plain Tailwind CSS v4 only |
| Icon library | none — Phase 1 has no icons |
| Font | Inter (Next.js default via `next/font/google`) |

**Rationale:** D-06 locks "no design system" for Phase 1. Glassmorphism, shadcn, and Framer Motion are Phase 6 scope. These pages must be functional and readable — not visually polished.

**Tailwind v4 note:** No `tailwind.config.js`. All theme extensions go in `src/app/globals.css` using `@theme`. CSS custom properties are the extension mechanism.

---

## Spacing Scale

Tailwind v4 spacing tokens used (multiples of 4):

| Token | Tailwind Class | Value | Usage |
|-------|---------------|-------|-------|
| xs | `p-1` / `gap-1` | 4px | Inline label-to-input gaps |
| sm | `p-2` / `gap-2` | 8px | Error message top margin, helper text |
| md | `p-4` / `gap-4` | 16px | Input internal padding, form field gaps |
| lg | `p-6` / `gap-6` | 24px | Card internal padding, button top margin |
| xl | `p-8` / `gap-8` | 32px | Card max inner content width padding |
| 2xl | `py-12` | 48px | Vertical centering buffer (top/bottom of page) |
| 3xl | — | 64px | Not used in Phase 1 |

Exceptions:
- Touch target minimum: 44px height on all interactive elements (`min-h-[44px]` on buttons and inputs). Required for mobile accessibility regardless of visual padding.
- Card max-width: `max-w-sm` (384px) — Tailwind preset, not a custom token.

## Typography

| Role | Size | Tailwind Class | Weight | Line Height | Usage |
|------|------|---------------|--------|-------------|-------|
| Heading | 24px | `text-2xl` | 600 `font-semibold` | 1.2 `leading-tight` | Page title ("Sign in to Pulse") |
| Body | 16px | `text-base` | 400 `font-normal` | 1.5 `leading-normal` | Descriptive text, nav links |
| Label | 14px | `text-sm` | 500 `font-medium` | 1.4 `leading-snug` | Form field labels |
| Error | 14px | `text-sm` | 400 `font-normal` | 1.4 `leading-snug` | Inline validation errors |

Font stack: `Inter, system-ui, sans-serif`. Load via `next/font/google` in root layout — no external request at runtime.

## Color

Phase 1 uses a minimal dark theme that is directionally consistent with Phase 6 (Space Grey + Indigo) but does not implement glassmorphism or blur effects.

| Role | Hex | Tailwind Approximation | Usage |
|------|-----|----------------------|-------|
| Dominant (60%) | `#1C1C1E` | `bg-zinc-900` | Page background |
| Secondary (30%) | `#2C2C2E` | `bg-zinc-800` | Auth card background, input backgrounds |
| Border | `#3A3A3C` | `border-zinc-700` | Card border, input border |
| Body text | `#FFFFFF` | `text-white` | Primary text on dark background |
| Muted text | `#A1A1AA` | `text-zinc-400` | Placeholder text, helper text |
| Accent (10%) | `#6366F1` | `bg-indigo-500` | Submit button background only |
| Accent hover | `#818CF8` | `hover:bg-indigo-400` | Submit button hover state only |
| Destructive | `#EF4444` | `text-red-400` | Error messages and error borders only |

Accent (`#6366F1`) reserved for:
- Submit button background (`/auth/login` Sign In button, `/auth/signup` Create Account button)
- No other elements in Phase 1

Destructive (`#EF4444`) reserved for:
- Inline form error messages
- Input border when field has a validation error (`border-red-500`)
- No destructive action confirmation needed in Phase 1 (sign-out is not destructive — no confirmation required)

**Phase 6 alignment:** These hex values match the Phase 6 Space Grey palette (`#1C1C1E`, `#2C2C2E`, `#3A3A3C`) and Electric Indigo accent (`#6366F1`, `#818CF8`) verbatim. Phase 6 adds glassmorphism layers on top of this same color foundation — Phase 1 tokens will not be replaced.

## Component Specifications

### Input Field

```
Anatomy: label (above) → input element → error message (below, conditional)

Label:
  - text-sm font-medium text-white
  - margin-bottom: 4px (mb-1)

Input element:
  - width: w-full
  - padding: px-4 py-3 (12px top/bottom, 16px left/right)
  - min-height: 44px (touch target)
  - background: bg-zinc-800
  - border: border border-zinc-700
  - border-radius: rounded-md (6px)
  - text: text-base text-white
  - placeholder: placeholder:text-zinc-400
  - focus ring: focus:outline-none focus:ring-2 focus:ring-indigo-500 focus:border-transparent
  - error state: border-red-500 focus:ring-red-500

Error message (conditional):
  - text-sm text-red-400
  - margin-top: 4px (mt-1)
  - role="alert" aria-live="polite"
```

### Button (Primary / Submit)

```
Anatomy: full-width block button

Default:
  - width: w-full
  - padding: px-4 py-3
  - min-height: 44px
  - background: bg-indigo-500
  - text: text-base font-semibold text-white
  - border-radius: rounded-md
  - cursor: cursor-pointer

Hover:
  - bg-indigo-400
  - transition: transition-colors duration-150

Focus:
  - focus:outline-none focus:ring-2 focus:ring-indigo-500 focus:ring-offset-2 focus:ring-offset-zinc-900

Disabled / Loading:
  - opacity-50 cursor-not-allowed
  - aria-disabled="true"
  - Show "Signing in..." / "Creating account..." text (no spinner component in Phase 1)

Active:
  - bg-indigo-600
```

### Auth Card / Container

```
Page wrapper:
  - min-h-screen bg-zinc-900
  - flex items-center justify-center
  - px-4 py-12 (horizontal padding for mobile safety, vertical breathing room)

Card:
  - w-full max-w-sm
  - bg-zinc-800
  - border border-zinc-700
  - rounded-xl (12px)
  - p-8 (32px internal padding)
  - NO box-shadow, NO backdrop-blur (Phase 6 only)

Card heading:
  - text-2xl font-semibold text-white
  - mb-6 (24px below heading before first field)

Form:
  - flex flex-col gap-4 (16px between field groups)
  - Button has mt-2 (8px extra above submit, separating from last field)
```

### Secondary / Text Link

```
Used for "Don't have an account? Sign up" links

  - text-sm text-indigo-400
  - hover:text-indigo-300
  - underline-offset-2 hover:underline
  - focus:outline-none focus:ring-2 focus:ring-indigo-500 rounded-sm

```
Not a primary action — styled as a secondary/ghost button

  - px-4 py-2

  - border border-zinc-700 rounded-md

|-------|---------|----------|
| Default | Input | `border-zinc-700` background `bg-zinc-800` |
| Focus | Input | `ring-2 ring-indigo-500 border-transparent outline-none` |
| Error | Input | `border-red-500 ring-2 ring-red-500` |

| Active | Primary button | `bg-indigo-600` |
| Loading | Primary button | `opacity-50 cursor-not-allowed` + button text changes to in-progress copy |

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Form labels | Every `<input>` has an explicit `<label>` with `htmlFor` matching `id`. No placeholder-only labels. |
| Error announcements | Error `<p>` elements have `role="alert"` and `aria-live="polite"` so screen readers announce them on insertion. |
| Button loading state | Button `aria-disabled="true"` when submitting. Button text changes to indicate loading state ("Signing in..."). |
| Keyboard navigation | Natural tab order: Email → Password → [Confirm Password on signup] → Submit → Cross-link. No `tabindex` manipulation needed. |
| Input types | `type="email"` on email field (triggers mobile keyboard). `type="password"` on password fields (masks input). |
| Autocomplete | `autocomplete="email"`, `autocomplete="current-password"` (login), `autocomplete="new-password"` (signup). |
| Page title | Each page sets a unique `<title>` via Next.js `metadata` export: "Sign In — Pulse", "Create Account — Pulse", "Dashboard — Pulse". |
| Color contrast | White text (`#FFFFFF`) on zinc-800 (`#2C2C2E`): contrast ratio ~14:1. Zinc-400 (`#A1A1AA`) on zinc-900 (`#1C1C1E`): ~5.6:1. Both pass WCAG AA. Indigo-400 (`#818CF8`) on zinc-900: ~5.1:1 — passes WCAG AA for normal text. |
| Focus visible | `focus:outline-none focus:ring-2` pattern used consistently — ring is always visible. Never `outline: none` without a visible focus alternative. |
| Form submission | `<form>` with `action` pointing to Server Action. No `onSubmit` JavaScript required for baseline function. |

## Phase 6 Alignment Notes

These notes are for the Phase 6 researcher — not for Phase 1 implementation.

| Phase 1 Element | Phase 6 Evolution |
|-----------------|------------------|
| `bg-zinc-900` page background | Remains `#1C1C1E` — same hex, may add subtle radial gradient |
| `bg-zinc-800` card | Replaced with `bg-white/5 backdrop-blur-md` glassmorphism card |
| `border-zinc-700` | Replaced with `border-white/10` |
| `bg-indigo-500` accent | Remains `#6366F1` — same hex, adds hover glow / gradient |
| Plain `<form>` | Wraps with Framer Motion `<motion.div>` for entrance animation |
| Static error messages | Animate in with `AnimatePresence` |

Phase 1 CSS custom properties in `globals.css` should pre-declare:
```css
@theme {
  --color-surface: #2C2C2E;
  --color-base: #1C1C1E;
  --color-border: #3A3A3C;
  --color-accent: #6366F1;
  --color-accent-hover: #818CF8;
}
```
This lets Phase 6 swap glassmorphism values in one place without hunting inline classes.
