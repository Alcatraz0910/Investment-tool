## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Comma-formatted numerics | HL exports `"2,461.696"` for quantity — Supabase NUMERIC cast fails | blocking | `parseRows` strips commas from both quantity and value before returning |
| Hiding Supabase errors | `return { error: 'Something went wrong' }` hid the missing-column root cause for a full session | advisory | Use `dbError(err)` helper — checks `err.code === '42703'` → schema migration message |
| Keyword overreach in fallback | `lower.includes('price')` matched per-share price column, not holding value | advisory | Value keyword list: `value`, `worth`, exact `"market value"` only — never `price` or `market` alone |
