# Plan 07-03: ImportCSVModal Component

<objective>
Create `pulse/src/components/ImportCSVModal.tsx` — a multi-step modal (3 steps for generic CSV; 2 steps for HL/AJ Bell) replicating the HoldingModal accessibility pattern. Steps: Upload → Map Columns (skipped for auto-detected brokers) → Preview + Confirm. Uses `useTransition` (not `useActionState`) to call `importHoldings`. All strings from UI-SPEC copywriting contract.
</objective>

<threat_model>
## Threat Model (ASVS L1)

| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T-03-01 | Non-.csv file accepted by drag-and-drop | MEDIUM | `file.name.endsWith('.csv')` check + inline error "Please upload a .csv file" |
| T-03-02 | Forbidden words in user-facing copy ("advice", "recommend") | HIGH | Grep gate in acceptance_criteria: count of forbidden words must be 0 |
| T-03-03 | Preview shows raw pence values (user confused by large numbers) | HIGH | GBX→£ conversion via `convertGbxToGbp` applied before preview; value column always shows £ |
| T-03-04 | Replace mode triggered without user seeing warning | HIGH | Replace-all amber warning banner displayed in step 3 whenever mode === 'replace' |
| T-03-05 | Focus not returned to trigger button on modal close | LOW | triggerRef pattern from HoldingModal — restore focus on close |
</threat_model>

const triggerRef = useRef<HTMLElement | null>(null)
useEffect(() => {
  if (isOpen) {
    triggerRef.current = document.activeElement as HTMLElement
  } else if (triggerRef.current) {
    triggerRef.current.focus()
    triggerRef.current = null
  }
}, [isOpen])

useEffect(() => {
  if (!isOpen) return
  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key === 'Escape') onClose()
  }
  document.addEventListener('keydown', handleKeyDown)
  return () => document.removeEventListener('keydown', handleKeyDown)
}, [isOpen, onClose])

**"Next" button validation in step 2:**
```typescript
function handleMappingNext() {
  const tickerMapped = Object.values(columnMapping).includes('Ticker *')
  const quantityMapped = Object.values(columnMapping).includes('Quantity *')
  if (!tickerMapped || !quantityMapped) {
    setMappingError('Ticker and Quantity columns are required')
    return
  }
  setMappingError('')
  // Build preview using manual mapping
  const tickerCol = Object.entries(columnMapping).find(([, v]) => v === 'Ticker *')?.[0] ?? ''
  const quantityCol = Object.entries(columnMapping).find(([, v]) => v === 'Quantity *')?.[0] ?? ''
  const valueCol = Object.entries(columnMapping).find(([, v]) => v === 'Value (£)')?.[0] ?? ''
  const categoryCol = Object.entries(columnMapping).find(([, v]) => v === 'Category')?.[0] ?? null
  buildPreview(rawRows, parsedHeaders, { tickerCol, quantityCol, valueCol, categoryCol, gbx: false, name: 'Generic' }, existingTickers)
  setStep(3)
}
```

function handleConfirm() {
  const importRows = previewRows
    .filter(r => r.status !== 'invalid')
    .map(r => ({ ticker: r.ticker, quantity: r.quantity, value: r.value, category: r.category }))
  startTransition(async () => {
    const result = await importHoldings(importRows, mergeMode)
    if (result.error) {
      setImportError(result.error)
    } else {
      onClose()
    }
  })
}
