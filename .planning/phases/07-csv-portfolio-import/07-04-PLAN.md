# Plan 07-04: PortfolioTab Integration

<objective>
Wire `ImportCSVModal` into `PortfolioTab`: add an "Import CSV" button to the Holdings section header (next to "Add Holding"), mount the modal in the component, pass `existingTickers` as a Set from the current holdings prop. Ends with a manual smoke-test checkpoint to verify the full import flow works end-to-end.
</objective>

<threat_model>
## Threat Model (ASVS L1)

| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T-04-01 | Modal opened without passing existingTickers, causing all rows to appear Valid instead of Duplicate | MEDIUM | Pass `new Set(holdings.map(h => h.ticker))` to ImportCSVModal prop |
| T-04-02 | "Import CSV" button style breaks the Holdings header layout on small screens | LOW | Button uses same ghost style as "Add Holding" — existing layout tested in Phase 10 mobile pass |
</threat_model>

## Task 1: Add "Import CSV" button and mount ImportCSVModal in PortfolioTab

<read_first>
- pulse/src/components/PortfolioTab.tsx (full file — understand existing modal state, Holdings header layout, holdings prop type)
- pulse/src/components/ImportCSVModal.tsx (check its props interface — needs onClose and existingTickers)
- .planning/phases/07-csv-portfolio-import/07-UI-SPEC.md (§Component Visual Inventory — "Import CSV" button ghost style)
</read_first>

<action>
In `pulse/src/components/PortfolioTab.tsx`, make these changes:

**1. Add import at top of file:**
```typescript
import { ImportCSVModal } from '@/components/ImportCSVModal'
```

**2. Add importModalOpen state (alongside existing modalOpen state):**
```typescript
const [importModalOpen, setImportModalOpen] = useState(false)
```

**3. Add "Import CSV" button to the Holdings section header.**
Find the Holdings section header that contains the "Add Holding" button. Add the "Import CSV" button immediately before it:
```tsx
{/* "Import CSV" button — ghost style matching "Add Holding" */}
<button
  onClick={() => setImportModalOpen(true)}
  className="bg-surface border border-border rounded-lg px-3 py-2 text-sm text-zinc-300 hover:text-white hover:border-zinc-500 min-h-[44px] focus:outline-none focus:ring-2 focus:ring-indigo-500"
>
  Import CSV
</button>
```

**4. Mount ImportCSVModal in the JSX (alongside existing HoldingModal mount):**
```tsx
{importModalOpen && (
  <ImportCSVModal
    onClose={() => setImportModalOpen(false)}
    existingTickers={new Set(holdings.map(h => h.ticker))}
  />
)}
```

**5. Verify ImportCSVModal's props interface matches what PortfolioTab passes:**
`ImportCSVModal` must accept:
```typescript
interface ImportCSVModalProps {
  onClose: () => void
  existingTickers: Set<string>
}
```
If the prop interface in `ImportCSVModal.tsx` doesn't include `existingTickers`, update it there too.
</action>

<action>
**This task requires manual browser verification.** Start the dev server and verify each flow:

```bash
cd pulse && npm run dev
```

Open http://localhost:3000/dashboard in a browser, navigate to Portfolio tab.

**Smoke test checklist:**

1. **"Import CSV" button visible** in Holdings section header, next to "Add Holding"
2. **Click "Import CSV"** → ImportCSVModal opens, shows "Import CSV" title, Step 1 of 3, drop zone
3. **Drag a non-.csv file onto drop zone** → error message "Please upload a .csv file" appears inline
4. **Drag a generic .csv file** → step advances to "Map Columns" (Step 2 of 3), CSV column headers listed
5. **Leave Ticker unmapped, click Next** → error "Ticker and Quantity columns are required"
6. **Map Ticker and Quantity, click Next** → advances to "Review Import" (Step 3 of 3), preview table shown
7. **Select "Replace all"** → amber warning banner appears counting holdings to be removed
8. **Select "Merge"** → amber warning banner disappears
9. **Click "Confirm Import"** → button shows "Importing…", modal closes on success, holdings table updates
10. **Press Escape** → modal closes; focus returns to "Import CSV" button
11. **Test with HL-format CSV** (headers: Stock, Units Held, Value (p)):
    - Broker banner "Hargreaves Lansdown format detected" appears
    - Modal auto-advances to step 2 of 2 (Preview) after ~1.5s
    - Value column shows £ amounts (not raw pence)
</action>
