## Spacing Scale

| Token | Value | Usage |

## Component Inventory

### SIG-01 Consensus chip

**Host:** "All Picks" table, Holding cell (`<td className="py-2 pr-2">`)
**Condition:** `item.creators.length >= 2`
**Placement:** Below ticker name and instrument name `<p>`, inline-block
**Shape:** Rounded rectangle (`rounded`) — matches `CONVICTION_CLASS` shape
**Size:** `text-xs font-semibold px-1.5 py-0.5`
**Colors:** emerald (see signal color table above)
**Label:** `Consensus` (no arrow, no icon)
**Interactive:** None — display only

```
[VWRL]     ← ticker link
[Vanguard] ← name
[Consensus] ← chip, new
```

### SIG-02 Sentiment trend badge

**Host:** Per-creator card, header row — beside `<p className="text-xl font-semibold text-white">{wl.creatorName}</p>`
**Condition:** `computeSentimentTrend(stable, latest) !== null`; no badge if `profile_latest` is null
**Placement:** Inline with creator name in `flex items-center gap-2 flex-wrap` container
**Shape:** Pill (`rounded-full`) — matches macro-theme chip shape from Phase 13
**Size:** `text-xs font-semibold px-2 py-0.5`
**Colors:** green (bullish) or amber (cautious) — see signal color table
**Labels:**
- Bullish: `Trending bullish` (no arrow prefix — plain text only; no financial advice language)
- Cautious: `Trending cautious`
**Interactive:** None — display only
**Tie rule:** `towardBullish === towardCautious` → no badge rendered (null returned)

### SIG-03 Contradiction badge

**Host:** Per-creator card, header row — beside creator name (same flex container as SIG-02)
**Condition:** `runContradictionCheck(stable, latest).hasContradiction === true`; no badge if `profile_latest` is null
**Placement:** After SIG-02 badge (if both present) in flex row
**Shape:** Pill (`rounded-full`) — consistent with SIG-02
**Size:** `text-xs font-semibold px-2 py-0.5`
**Colors:** red — see signal color table
**Label:** `Contradiction` (no warning glyph — plain text; screen readers read it correctly without symbol)
**Cursor:** `cursor-help` — signals there is a tooltip
**Tooltip:** Native HTML `title` attribute containing `reason` string from `ContradictionResult`
  - Reason strings are template-generated (not AI prose): e.g. `AAPL was high conviction but absent from recent picks; Technology: bullish → cautious`
  - No financial advice language possible (deterministic template output)
**Interactive:** Hover reveals `title` tooltip — browser-native; no JS required

### SIG-04 Cadence — card opacity + badge

**Host:** Outer `motion.div` card for per-creator section
**Condition:** `wl.profileLatestNull === true` (new field on `CreatorWatchList`)
**Opacity:** `style={{ opacity: 0.8 }}` applied to outermost `motion.div` (not a child element)
**Badge host:** Inside creator header flex row, beside creator name
**Badge shape:** Pill (`rounded-full`)
**Badge size:** `text-xs font-semibold px-2 py-0.5`
**Badge colors:** zinc/muted — see signal color table
**Badge label:** `No recent posts`
**Interactive:** None — display only
**Note:** SIG-02 and SIG-03 badges are not rendered when `profile_latest` is null — only SIG-04 badge appears

## Interaction Contract

### Tooltip (SIG-03)

- Mechanism: `title` attribute on the badge `<span>`
- Trigger: Browser hover (no custom JS)
- Content: `reason` string from `runContradictionCheck` — 1–3 semicolon-separated reason phrases
- Fallback: `title={reason ?? undefined}` — no title attribute if reason is null (no empty tooltip)
- Accessibility: `cursor-help` class signals tooltip is available

### Opacity transition (SIG-04)

- Mechanism: `style={{ opacity: wl.profileLatestNull ? 0.8 : 1 }}`
- Applied to: outermost `motion.div` per-creator card
- No animation required — static opacity value; Framer Motion `animate` not needed for this property
- Existing `itemVariants` animation (`opacity: 0 → 1`) still runs on mount; the 0.8 value is the final settled state

### No new interactive controls

Phase 14 adds no new buttons, modals, popovers, drawers, or form inputs. All signal badges are read-only indicators.

## Copywriting Contract

| Element | Copy |
|---------|------|
| SIG-01 chip label | `Consensus` |
| SIG-02 bullish badge label | `Trending bullish` |
| SIG-02 cautious badge label | `Trending cautious` |
| SIG-03 badge label | `Contradiction` |
| SIG-03 tooltip — ticker absent | `{TICKER} was high conviction but absent from recent picks` |
| SIG-03 tooltip — stance flip | `{Sector}: {old stance} → {new stance}` |
| SIG-03 tooltip — multiple reasons | reasons joined with `; ` (semicolon space) |
| SIG-04 badge label | `No recent posts` |
| Empty state (no creators) | Heading: `No creators tracked` / Body: `Go to the Creators tab to track a creator, then refresh them to generate picks.` (unchanged from Phase 12) |
| No profile state | `Refresh this creator to generate picks` (unchanged) |
| No tickers state | `This creator has not cited specific tickers recently` (unchanged) |
| Error banner | `{server-returned error string}` — displayed via `role="alert" aria-live="assertive"` (unchanged pattern) |
| Disclaimer footer | `Watch list picks are derived from creator content and are not financial advice. Always do your own research.` (unchanged) |

Copywriting rules:
- No "advice", "recommend", or "suggest" in any badge label
- Badge labels are observational: describe what the data shows, not what the user should do
- Tooltip reason strings use arrow notation (`→`) for stance changes — factual, not prescriptive

## States Per Signal

| Signal | No data state | Data state | Shown when |
|--------|--------------|------------|------------|
| SIG-01 | No chip | `Consensus` chip | `item.creators.length >= 2` |
| SIG-02 | No badge | `Trending bullish` or `Trending cautious` | `profile_latest !== null` AND majority drift |
| SIG-03 | No badge | `Contradiction` badge + tooltip | `profile_latest !== null` AND contradiction detected |
| SIG-04 | No badge / full opacity | `No recent posts` badge + 80% opacity | `wl.profileLatestNull === true` |

When `profile_latest === null`: only SIG-04 badge is shown. SIG-02 and SIG-03 are suppressed.
When `profile_stable === null` (`!wl.hasProfile`): no signal badges of any kind; existing "Refresh this creator" state shown.

## Accessibility

- All badge `<span>` elements are inline text — screen readers read label text directly
- `cursor-help` on SIG-03 badge communicates tooltip availability to sighted users
- SIG-04 opacity (0.8) does not affect text readability at standard zoom (contrast ratio preserved)
- No ARIA roles needed on badge chips — they are informational text nodes, not interactive controls
- Existing `role="alert"` pattern on error banners is unchanged
- Focus ring pattern (`focus:ring-2 focus:ring-indigo-500`) applies only to existing interactive controls; signal badges receive no focus ring (non-interactive)
