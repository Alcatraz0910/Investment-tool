Standard 8-point scale. Multiples of 4 only.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline separators |
| sm | 8px | Compact row padding, button icon gap |
| md | 16px | Default card padding, section gap, input padding |
| lg | 24px | Section vertical spacing, watch list section gap |
| xl | 32px | Major layout gap between creator sections |
| 2xl | 48px | Page-level top/bottom padding |
| 3xl | 64px | Reserved; not used in this phase |

Exceptions:
- Touch targets: minimum 44px height on all interactive elements (buttons, inputs, sliders). Source: existing PortfolioTab.tsx `min-h-[44px]` pattern — apply to all new controls.
- Budget number input: `w-28` width (112px) to fit £0–£20,000 values.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1C1C1E` (--color-base) | Page background, tab content background |
| Secondary (30%) | `#2C2C2E` (--color-surface) + `zinc-800/50` | Cards, creator sections, glassmorphism panels |
| Accent (10%) | `#6366F1` (--color-accent) | Reserved list below |
| Destructive | `#F87171` (red-400) | Inline error text only (no destructive actions in this phase) |

Accent (`#6366F1` / `#818CF8` on hover) is reserved for:
1. Primary action buttons ("Set Budget", "Refresh Prices")
2. Focus rings (`focus:ring-2 focus:ring-indigo-500`)
3. Conviction badge for "high" conviction items
4. Tracked state indicator (creator section header accent line)

Accent is NOT used for:
- Body text
- Table data values
- Labels or meta text
- Secondary/ghost buttons (use `border-zinc-700`, `text-zinc-400`)

Semantic colors:
- `text-amber-400` — price stale warning (>24h old, matches PortfolioTab pattern)
- `text-red-400` — error messages and destructive action labels
- `text-zinc-500` — price unavailable dash (—), placeholder text, empty secondary copy
- `text-zinc-400` — secondary labels, meta text, creator rationale text

## Interaction Contracts

### Budget Save Flow

1. User clicks "Edit" next to "£X / month" display in a creator header.
2. Display text is replaced by `£` prefix + number input + "Save Budget" + "Cancel".
3. User changes value; clicks "Save Budget".
4. Button shows "Saving…" + disabled.
5. On success: input row collapses back to display text with new value.
6. On error: `text-sm text-red-400` error appears below the input row. Input remains open.
7. "Cancel" always restores display text without saving.

### Refresh Prices Flow

1. User clicks "Refresh Prices" button.
2. Button shows spinner + disabled. All price cells in all creator sections show previous value (no skeleton — matches Phase 8 pattern).
3. On success: all price cells update with new values and stale coloring recalculates.
4. On partial error: `text-sm text-red-400` banner below heading row — "Could not fetch prices for: TICK, TICK2". Per existing PortfolioTab.tsx `priceError` pattern.
5. On full error: same banner with generic message.

### Tab Navigation

Tab bar removes "ISA" entry. Remaining tabs: "Portfolio" | "Creators" | "Watch List".

Tab "Watch List" replaces the existing "Plan" / "Buy List" tab at the same position in the tab order (3rd position). The tab label is exactly `"Watch List"` (not "Buy List", not "Plan").

### Animation

Framer Motion pattern: match creators-tab.tsx stagger pattern for creator sections:

```tsx
const sectionVariants = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: { staggerChildren: 0.06 } },
}
const itemVariants = {
  hidden: { opacity: 0, y: 8 },
  visible: { opacity: 1, y: 0, transition: { duration: 0.25, ease: 'easeOut' } },
}
```

AnimatePresence wraps the creator section list. Ticker rows within a section do not animate independently (performance — up to 20 rows per creator).

## Accessibility Baseline

Minimum requirements extracted from existing component patterns:

- All interactive elements: `focus:outline-none focus:ring-2 focus:ring-indigo-500` focus ring
- All interactive elements: `min-h-[44px]` touch target height
- Budget input: `<label>` with `htmlFor` linking to input id; screen-reader-only label via `sr-only` if label not visible
- Price "—" cells: `aria-label="Price not available"` on the dash span
- Qty "—" cells: `aria-label="Price needed to calculate quantity"`
- Error messages: `role="alert" aria-live="polite"` (assertive for price refresh errors, polite for budget save errors)
- Tab navigation: existing tab bar pattern — no changes to tab keyboard behavior
- Conviction and layer badges: decorative; text is sufficient; no additional aria needed
- Disclaimer footer: `aria-label` not needed; visible text is self-explanatory
