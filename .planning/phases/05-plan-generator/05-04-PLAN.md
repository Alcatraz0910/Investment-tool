      )

      return (

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser slider → ContributionCalculator | budget value from slider (integer 200-1000); not persisted to DB directly |
| Server component → upsertBuyList | PlanResult computed from DB values (server-authoritative); no client input to plan row |
| User → Plan tab URL | ?tab=plan is a display-only parameter; data fetched server-side for authenticated user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Tampering | ContributionCalculator budget slider | accept | Slider only affects display; upsertBuyList is called from server component with server-computed values — client slider budget is never written to DB |
| T-05-04-02 | Information Disclosure | Plan tab renders another user's data | mitigate | page.tsx fetches holdings/ISA with `.eq('user_id', user.id)` (RLS + app-level scope); PlanTab receives only the current user's data |
| T-05-04-03 | Denial of Service | void upsertBuyList on every page load | accept | Single upsert per page load per user; idempotent (upsert overwrite); at typical v1 scale (1 user) this is negligible |
</threat_model>
