## Interaction Contracts

### Refresh Prices Button (Portfolio Tab)

- **Placement:** Right side of Holdings section header, alongside existing "Import CSV" and "+ Add Holding" buttons.
- **Rest state:** `bg-indigo-500 hover:bg-indigo-400 text-white text-sm font-semibold rounded-md px-3 min-h-[44px]` — label: "Refresh Prices"
- **Pending state:** Replace label with `animate-spin` SVG spinner (16×16, same as `refresh-button.tsx` pattern); `disabled:opacity-75`; `aria-label="Refreshing prices..."`.
- **Done state:** Button returns to rest label. Holdings rows update with new price values via `revalidatePath('/dashboard')`.
- **Error state:** Inline `role="alert"` text below button — `text-sm text-red-400`. Copy: "Could not fetch prices. Please try again."
- **Schema not migrated error:** "Database schema is out of date. Run the Phase 8 migration in Supabase SQL Editor."
- **Source:** `refresh-button.tsx` spinner pattern; D-05.

### Refresh Prices Button (Buy List Tab)

- **Placement:** Above the `BuyListTable`, in the `ContributionCalculator` layout, right-aligned.
- **Appearance:** Same class spec as Portfolio Refresh Prices button.
- **Pending state:** Spinner + `disabled:opacity-75`.
- **Done state:** `BuyListTable` re-renders with prices in the new column (React state update, no page reload).
- **Source:** D-06.

### Chart Expand/Collapse (Per Holding Row)

- **Trigger:** Icon button at the right end of each holding row. Icon: line-chart SVG (inline, 16×16). `min-h-[44px] min-w-[44px]`.
- **Rest state:** `text-zinc-500 hover:text-zinc-300` (chart not open).
- **Active state:** `text-accent` (`text-indigo-400`) when chart is expanded for this row.
- **aria-label:** `"Show chart for {ticker}"` / `"Hide chart for {ticker}"` toggled on state.
- **Expand animation:** `AnimatePresence` + `motion.div` `initial={{ height: 0, opacity: 0 }}` → `animate={{ height: 'auto', opacity: 1 }}` → `exit={{ height: 0, opacity: 0 }}`, `transition={{ duration: 0.2, ease: 'easeOut' }}`, `overflow: 'hidden'`.
- **Panel appearance:** Full row width; no border of its own — the containing row card provides the border; `pt-2 pb-4 px-4` internal padding.
- **Only one chart open at a time:** `expandedChartId: string | null` state; clicking another row's icon collapses the current and expands the new one.
- **Source:** D-03; RESEARCH.md Pattern 4; existing `BuyListTable.tsx` rationale accordion pattern.

### Current Price Column (Portfolio Tab)

- **Column header:** "Price" — `text-xs text-zinc-500 uppercase tracking-wide`.
- **Value (fetched):** `text-sm text-white` — formatted as `£{price.toFixed(2)}`. Note: GBp tickers display in £ after ÷100 conversion (see RESEARCH.md Assumption A2 / Open Question 1).
- **Value (null, never fetched):** `text-sm text-zinc-500` — render literal `—` (em dash).
- **Column always visible:** No conditional rendering. Layout never shifts on first refresh. Source: D-08.

### As-Of Timestamp (Portfolio Tab)

- **Format:** UK locale datetime — `toLocaleString('en-GB')` (e.g. "17/05/2026, 14:32:00").
- **Fresh (< 24h):** `text-xs text-zinc-400`.
- **Stale (≥ 24h):** `text-xs text-amber-400`.
- **Null (never fetched):** Render nothing in this cell (empty, not a dash — only the Price cell shows `—`).
- **Source:** D-07; RESEARCH.md Pattern 6.

### Price Column (Buy List Tab)

- **Column header:** "Price" — matches existing `BuyListTable` header style (`text-xs text-zinc-500 uppercase tracking-wide`).
- **Value (fetched):** `text-sm text-white` — `£{price.toFixed(2)}`.
- **Value (null / not yet fetched):** `text-sm text-zinc-500` — `—`.
- **Column position:** Between "Ticker" and "Amount" columns. Grid layout extends to `grid-cols-[1fr_auto_1fr_auto]` or equivalent.
- **Source:** D-02; REQUIREMENTS PRICE-02.
