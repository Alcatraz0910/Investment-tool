### 4. Add handleRefreshBuyListPrices handler

Read the file to understand the variable name for the current buy list plan and how items are accessed. Then write the handler:
```typescript
function handleRefreshBuyListPrices() {
  // Guard: only run if there is an active buy-list plan with items
  // Adapt 'plan' and 'plan.items' to the actual variable names used in this component
  if (!plan || plan.type !== 'buy-list' || !plan.items?.length) return
  setBuyListPriceError(null)
  const tickers = plan.items.map((i: { ticker: string }) => i.ticker)
  startPricesTransition(async () => {
    const result = await fetchTickerPrices(tickers)
    if (result.error) {
      setBuyListPriceError(result.error)
    } else if (result.prices) {
      setBuyListPrices(result.prices)
    }
  })
}
```

If the buy list plan is named differently (e.g. `buyList`, `generatedPlan`, `result`), adapt accordingly. The key logic — extracting `ticker` from each item and calling `fetchTickerPrices` — must remain.
