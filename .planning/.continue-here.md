## Critical Anti-Patterns (do NOT repeat these)
- **Animation variants defined outside component**: causes stale closure issues with `useReducedMotion`; always define inside component (15: IN-03)
- **setTimeout not stored in ref**: causes state update on unmounted component; always use `useRef` + clear on unmount (15: IN-04)
- **Array index as key**: use stable composite keys (e.g. `${ticker}-${index}`) on mapped lists (15: IN-02)
