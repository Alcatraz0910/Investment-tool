# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-07
**Phases:** 1–6
**Total Plans:** 30

## Overview

Pulse v1.0 MVP — full-stack personal UK ISA investment planning tool. Ingests YouTube creator transcripts, extracts asset allocation strategies via Claude RAG, blends multiple creator strategies using trust weights, and produces a concrete monthly Buy List showing exactly how to split a budget to move the portfolio toward the target allocation. Delivered as a glassmorphism Next.js 15 dashboard with Framer Motion transitions, Recharts roadmap view, and a real-time contribution calculator.

## Milestone Summary

**Key Accomplishments:**
1. Full-stack Next.js 15 app with Supabase auth, 9-table RLS schema, and TypeScript domain types — shipped in one day
2. YouTube transcript pipeline with Pinecone RAG embeddings, idempotent refresh, and real-time status polling
3. Claude strategy extraction engine — RAG retrieval, tool_use extraction, contradiction detection, versioned snapshots
4. Multi-creator strategy blending with per-category trust weights and Blend Summary influence display
5. ISA-aware plan generator (`generatePlan`) with decimal.js arithmetic, fill-ticker routing, and sub-100ms slider recompute
6. Glassmorphism dashboard with 83 passing vitest tests, Recharts roadmap view, and Framer Motion transitions

**Key Decisions:**
- Manual portfolio entry for v1 (TrueLayer deferred to v2)
- RAG pattern for Claude (Pinecone → chunks → Claude) — never full transcript dumps
- `decimal.js` for all £ arithmetic — no native JS floats
- Information-only framing — no "advice"/"recommend"/"suggest" in any user-facing output
- UK tax year (6 Apr – 5 Apr) for ISA allowance tracking
- `generator.ts` zero server-only imports — enables client-side plan recomputation
