## v1 Requirements — Final Status

### Authentication
- [x] **AUTH-01**: User can sign up and log in with email/password (Supabase Auth) — ✓ Phase 1
- [x] **AUTH-02**: User session persists across browser sessions — ✓ Phase 1

### Creator Management
- [x] **CREATOR-01**: Admin can add or remove creators from the curated list — ✓ Phase 2 (seed-creators.sql)
- [x] **CREATOR-02**: User can view curated creator list and add to personal tracking list — ✓ Phase 2 (dedicated /dashboard/creators route in v1.0)
- [x] **CREATOR-03**: User can add a custom YouTube channel URL — ✓ Phase 2
- [x] **CREATOR-04**: User can remove any creator from their personal tracking list — ✓ Phase 2

### Transcript Pipeline
- [x] **TRANS-01**: Fetch transcripts for all videos published in last 12 months — ✓ Phase 3
- [x] **TRANS-02**: Transcripts stored in Supabase with creator ID, video ID, title, published date — ✓ Phase 3
- [x] **TRANS-03**: Transcript chunks embedded (OpenAI text-embedding-3-small) and stored in Pinecone — ✓ Phase 3
- [x] **TRANS-04**: Manual "Refresh" button per creator triggers re-fetch and re-embedding — ✓ Phase 3
- [x] **TRANS-05**: Last-refreshed timestamp displayed per creator — ✓ Phase 3

### Strategy Extraction
- [x] **STRAT-01**: Claude extracts implied asset allocation via RAG — ✓ Phase 4
- [x] **STRAT-02**: Each extraction is versioned (new snapshot per refresh, history preserved) — ✓ Phase 4
- [x] **STRAT-03**: Strategy includes confidence score and source video citations — ✓ Phase 4
- [x] **STRAT-04**: Contradictions between current and past stance flagged on strategy card — ✓ Phase 4

### Creator Trust & Blending
- [x] **BLEND-01**: Per-category trust weight slider (0–100%) per tracked creator — ✓ Phase 4
- [x] **BLEND-02**: PlanGenerator blends strategies using category weights (weighted average) — ✓ Phase 4
- [x] **BLEND-03**: Blend Summary shows per-creator influence % — ✓ Phase 4

### Portfolio Entry
- [x] **PORT-01**: User can manually add holdings (ticker, quantity, current value) — ✓ Phase 2
- [x] **PORT-02**: User can edit and delete existing holdings — ✓ Phase 2
- [x] **PORT-03**: User sets a monthly contribution amount in £ — ✓ Phase 2

### ISA Tracking
- [x] **ISA-01**: ISA allowance tracker shows remaining annual allowance — ✓ Phase 2 (restored in Phase 6 fix)
- [x] **ISA-02**: Plan Generator caps Buy List total to remaining ISA allowance — ✓ Phase 5
- [x] **ISA-03**: User can log ISA contributions manually (date + amount) — ✓ Phase 2 (restored in Phase 6 fix)

### Plan Generator
- [x] **PLAN-01**: PlanGenerator outputs Next-Month Buy List {ticker, category, amount_gbp, rationale} — ✓ Phase 5
- [x] **PLAN-02**: Buy List displays current allocation gap per asset class — ✓ Phase 5
- [x] **PLAN-03**: After creator refresh updates strategy, next Buy List reflects new blended allocation — ✓ Phase 5
- [x] **PLAN-04**: All plan output labelled "Creator-derived information — not financial advice" — ✓ Phase 5

### Dashboard & UI
- [x] **UI-01**: Glassmorphism dark mode (Space Grey + Electric Indigo palette; Framer Motion) — ✓ Phase 6
- [x] **UI-02**: Action Plan panel with Buy List — ✓ Phase 6
- [x] **UI-03**: Roadmap View (Creator's Vision vs Your Current Path trajectories) — ✓ Phase 6
- [x] **UI-04**: Contribution Calculator slider (£200→£1000, instant recalculation) — ✓ Phase 6
- [x] **UI-05**: Creator strategy card (allocation, confidence, last-refresh, contradiction flags) — ✓ Phase 6
