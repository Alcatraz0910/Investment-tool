## Unsatisfied Requirements

### CI-01 — Transcript scraping limited to 4 months (Phase 11)

**Root cause:** `pulse/src/lib/youtube/client.ts` line 85 uses a 28-day cutoff (`28 * 24 * 60 * 60 * 1000`). The function is exported as `listVideosLast4Weeks`. `transcript-pipeline.ts` line 34 imports and line 139 calls `listVideosLast4Weeks`. Phase 11 SUMMARY incorrectly states this was renamed to `listVideosLast4Months` — the rename did not occur.

**Impact:** Only the last 4 weeks of a creator's videos are embedded into Pinecone. The 4-month scraping requirement is not met.

**Fix:** Change line 85 cutoff to `120 * 24 * 60 * 60 * 1000`. Rename `listVideosLast4Weeks` to `listVideosLast4Months` everywhere.

---

### CI-02 — Two distinct extraction layers (Phase 11)

**Root cause:** Same as CI-01. Stable extractor filter looks back 120 days in Pinecone, but only 28 days of vectors exist. Both `profile_stable` (4-month query) and `profile_latest` (30-day query) draw from the same 28-day Pinecone pool. The fallback (retry without filter if 0 chunks) masks the issue but does not fix the semantic break.

**Impact:** The stable/latest distinction is meaningless for any creator. Phase 12's WatchListTab layer pills (Established / This Month) display correct labels but incorrect data.

**Fix:** Unblocked by fixing CI-01 (expand pipeline scraping to 4 months).

**File:** `pulse/src/app/dashboard/page.tsx` lines 159–165
**Requirements:** NEWS-03, NEWS-05

```ts
// Bug 1: user_creator_id does not exist on creator_strategies

const userCreatorIds = Object.values(userCreatorIdMap)
const { data: strategyRows } = await supabase
  .from('creator_strategies')
  .select('profile_stable')
  .in('user_creator_id', userCreatorIds)   // ← wrong column AND wrong ID set

// Fix: use creator_id with the trackedIds array already in scope (line 104)
const { data: strategyRows } = await supabase
  .from('creator_strategies')

  .in('creator_id', trackedIds)
```

`creatorSectors` is always `[]` on every page load. Claude's `generate_news_context` tool call always receives empty sectors. NEWS-03 sector cross-referencing and NEWS-05 creator card macro conditions are silently disabled at runtime.
